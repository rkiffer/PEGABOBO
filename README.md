# PEGABOBO MU Maps - v1.0

Site interativo para GitHub Pages + Firebase Firestore.

## Como atualizar no GitHub

1. Apague/substitua os arquivos antigos no repositório.
2. Envie todos estes arquivos e pastas descompactados:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `config.js`
   - `assets/maps/`
3. Commit changes.
4. Aguarde o GitHub Pages atualizar.

## Firebase

O `config.js` já contém o Firebase Config do projeto PEGABOBO.

Use Firestore em modo de teste durante os primeiros testes.
